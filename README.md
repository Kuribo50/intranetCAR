# intranetCAR

Intranet para CESFAM Dr. Alberto Reyes

## Características

- Directorio telefónico con anexos
- Búsqueda y filtrado de contactos
- Vista de tabla y cuadrícula
- Interfaz moderna y responsive

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS
- TanStack Table

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
